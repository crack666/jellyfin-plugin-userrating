User Rating

Dieses Plugin schreibt nicht in die Jellyfin-Quellen. Es injiziert ein Script in die Web-UI, das das vorhandene Feld UserData.Rating anzeigt, sortierbar macht und auf der Detailseite setzbar macht.

  • Sortierung: Eintrag Eigene Bewertung im Sort-Menü (clientseitig, weil der Server 10.11 UserRating ignoriert)
  • Poster: Note beim Hover auf dem Cover
  • Detailseite: Note neben der Community-Bewertung — Klick öffnet das Dropdown (10 → 1)

Quelle und Credit: github.com/crack666/jellyfin-plugin-userrating — gebaut mit Cursor / Grok 4.6.

Nach der Installation: Jellyfin neu starten, Web-UI hart neu laden (Strg+F5).

IMDb-Import

CSV-Import (IMDb ratings export) auf dieser Seite ist als Nächstes geplant. Bis dahin denselben Export lokal importieren, der UserData.Rating befüllt.
