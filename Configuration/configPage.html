User Rating

Personal rating (UserData.Rating) in the stock web UI: sort, cover badge (hover or always-on via the star in the library toolbar), set the score on the detail page. IMDb CSV import on this page. No fork of jellyfin-web. github.com/crack666/jellyfin-plugin-userrating

Native clients

Android, Android TV, FireTV, webOS and Chromecast know nothing about a personal rating. With this on, item responses carry it in CriticRating (scaled to 0–100) and sorting by critic rating sorts by it, so those clients can show and sort your scores. Responses only — the stored critic ratings are never written to and come back the moment you switch this off. The web UI shows the same value with a tomato icon while it is on.

IMDb import

IMDb → Your Ratings → Export. Required columns: Const (tt…) and Your Rating. Match on ProviderIds.Imdb. Only the personal score is written; play state is left alone.
